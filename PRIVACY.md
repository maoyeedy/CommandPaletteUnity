# Privacy Policy for Command Palette - Unity

Command Palette - Unity is a Microsoft PowerToys Command Palette extension for finding and opening local Unity projects.

## Data accessed by the app

The app reads Unity Hub's local project list from the user's Windows profile, typically located at:

`%APPDATA%\UnityHub\projects-v1.json`

This file may contain local Unity project names and file paths.

## How data is used

The app uses this local Unity Hub project information only to display Unity projects in Command Palette and to launch the selected project in the Unity Editor.

## Data collection and transmission

Command Palette - Unity does not collect, upload, sell, share, or transmit Unity project information to the developer or to any third party.

The app does not require a user account and does not include analytics, advertising, or telemetry.

## Local app behavior

When a user selects a Unity project, the app launches the local Unity Editor installed on the user's device.
